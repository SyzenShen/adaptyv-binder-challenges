## 3. 3D 取向与实际可及性（不只看距离）

1. **所有四个候选 patch 的残基 occGly = 0**：沉积糖链不遮挡任何 patch 残基自身的溶剂暴露。糖风险来自"成熟 human-type 糖链体积 + 结合分子靠近"，不是靶点表面已被盖住。
2. **Scheme 2（EPI_H_1）风险最高**：K335 距 N361 糖链仅 4.27 Å 且已有 11.3 Å² 被沉积糖（链 F）遮挡；331–343 一段距 N352/N361 糖链 6.6–10 Å。N352 与 N361 两个位点在空间上相邻（335 同时接近两者），成熟复杂型糖链会在此形成连续糖被。另该 patch 含 4 Cys/3 对二硫键（见 target_preparation.md）。
3. **EPI_H_2 的糖距离是"边缘距离"**：6.55–7.77 Å 出现在段边缘（D388/P389 对 N413 糖、P385 对 N352 糖、T397 对 N361 糖）；段中部（399–403）距糖 ≥12 Å。可通过 hotspot 侧重段中部规避。
4. **EPI_H_3 与 N413/N444 糖**：最小距离在段首 D416（N444 糖 7.78 Å）与埋藏的 H418（N413 糖 7.36 Å，relSASA 0.022，本身不接触溶剂）。段的结合面（暴露残基 E421/N422/E424/R427/R429/T430/K431）距糖链 12.6–21.5 Å。
5. **两段之间的序列缺口（404–415）才是糖链伸入区**：N413 自身带糖（1.44 Å 共价），E412 被 N444 糖（链 E）遮挡 30.2 Å²、距糖 3.26 Å，R414 距糖 3.99 Å，T415 4.44 Å。binder **不应设计成横跨缺口表面**；而几何审计显示两段在 3D 中直接相邻（见 cetuximab_distance_audit.md 与 checkpoint A+），不需要占据缺口。
6. **物种差异的一个额外含义**：N361 仅人有序列 sequon。若 binder 接触面依赖/贴近 N361 糖，人鼠实验行为可能系统性不同；远离该位点可降低该不确定性。

## 4. 结论（供确认点 A+，不做自动淘汰）

- 糖风险排序（沉积结构下界 + 成熟糖链外推）：**EPI_H_1（Scheme 2）高 ＞ EPI_H_2 边缘中等 ＞ EPI_H_3 低 ＞ EPI_H_4 低（N444 侧 7.46 Å）**。
- 不因"附近有糖"自动否定 patch：真实遮挡经 SASA 验证为零；但成熟 HEK293 糖链更大，生成后必须用"糖链存在/不存在"两种几何检查复核（阶段 3/4 加 glycan-aware clash 检查项）。
- 对 Scheme 1 的可执行修正：hotspot 优先 EPI_H_2 中段 + EPI_H_3 暴露面（421–431），避开 385/388/389 边缘与 404–415 缺口表面。
