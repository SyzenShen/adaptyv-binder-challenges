# adaptyv-binder-challenges

Computational protein-binder design work for the Anthropic x Adaptyv competition on Proteinbase. Each challenge is self-contained.

| Challenge | Target | Directory | Status |
|---|---|---|---|
| 1 | EGFR | [`challenges/egfr/`](challenges/egfr/) | closed (submission window ended 2026-10-07); see its README and STATE.md |
| 2 | TNF-alpha, neutral pH ON / acidic pH OFF, human + mouse | [`challenges/tnfa/`](challenges/tnfa/) | in progress; deadline 2026-10-11 23:59 AoE |

Layout: `challenges/<name>/` holds that challenge's data, scripts, tests, reports and notes. Nothing is shared between challenges, and
Challenge 1 conclusions are not reused for Challenge 2.

The repository was named `egfr-binder-challenge` until 2026-10-08.
